# Travel Planner

Web application for planning trips: travel plans, destinations, day-by-day
activities, expenses and budget, checklists, and plan sharing.

Course project — *Primena veb programiranja u infrastrukturnim sistemima*.

**Stack:** React + TypeScript (frontend) · Microsoft Service Fabric
microservices on ASP.NET Core (backend) · Microsoft SQL Server (persistence).

> Work in progress. Full setup instructions, architecture description and
> diagrams are added as the project is built.
